# samples/

Audios y salidas de pruebas manuales contra la API.

- `*.wav`, `*.mp3` (raíz) — muestras pequeñas y libres versionables (commiteables).
- `audio/` — audio de prueba **no** versionado (ignorado por `.gitignore`). Usar para descargas largas o material con derechos.
- `output/` — transcripciones generadas durante las pruebas (no versionado).

Ver [../docs/testing.md](../docs/testing.md) para el procedimiento.
